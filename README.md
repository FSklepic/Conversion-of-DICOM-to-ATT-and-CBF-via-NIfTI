# Conversion-of-DICOM-to-ATT-and-CBF-via-NIfTI
Step by step guide in transforming DICOM MRI photos into NIfTI and than extracting ATT and CBF values out of them.

For the execution of this project it is reccomended to use linux operating system althought it is possible to execute it on windows.

My setup consists of virtual box with ubuntu virtual OS with shared folder setup between ubuntu and my main windows os in which all programs will be run.
