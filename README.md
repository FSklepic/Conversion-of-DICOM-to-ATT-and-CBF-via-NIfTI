# Conversion-of-DICOM-to-ATT-and-CBF-via-NIfTI
Step by step guide in transforming DICOM MRI photos into NIfTI and than extracting ATT and CBF values out of them.

For the execution of this project it is reccomended to use linux operating system althought it is possible to execute it on windows using wsl or virtual box with ubuntu virtual OS with shared folder setup between ubuntu and my main windows os.

My setup will use Windows os with integrated WSL enviorment in which every step of the project will be executed.
